# WealthWise - Personal Finance Tracker

WealthWise is a full-stack personal finance management application developed using the MERN stack (MongoDB, Express.js, React.js, and Node.js). The project is designed to provide users with a simple and organized way to manage their personal finances from a single platform.

The application allows users to record and manage their income and expenses, categorize transactions, create savings goals, and monitor their overall financial progress. It also provides dashboard-based summaries and visual insights that help users understand their spending patterns and make more informed budgeting decisions.

## Project Objective

The primary objective of WealthWise is to develop a practical personal finance management system that enables users to:

* Manage income and expense records
* Categorize financial transactions
* Monitor their current financial balance
* Create and track savings goals
* Review spending patterns
* View financial summaries and visual insights

## Key Features

## Project Scope

The current scope of WealthWise focuses on personal financial tracking for individual users. The application covers income and expense management, transaction categorization, savings goals, financial dashboards, and visual insights.

The project does not include banking transactions, payment processing, investment execution, or professional financial advisory services.

## Future Scope

The application can be further enhanced with additional features such as recurring transactions, budgeting recommendations, financial notifications, data export, advanced analytics, and other personal financial planning tools.
